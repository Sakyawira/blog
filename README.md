# Sakya Idea Corner

A personal Markdown blog built with Astro, Tailwind CSS, and shadcn-style UI primitives.

## Commands

```bash
pnpm dev
pnpm check
pnpm build
pnpm format
```

Articles live in `src/content/blog/`. Add a Markdown or MDX file with the required frontmatter, commit it to `main`, and GitHub Actions can rebuild the static site for GitHub Pages.

The site is configured for `https://sakyawira.github.io/blog/`. Update `site` and `base` in `astro.config.mjs` if the repository or deployment URL changes.
